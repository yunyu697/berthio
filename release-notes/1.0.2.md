# Berthio 1.0.2

本版不加新功能，只做两件事：路径护栏整改、事故记录。目的是把 2026-11-06 误删用户目录的事故变成可追溯、可防复发的工程约束。

## 本版内容

1. **统一路径护栏**
   - PowerShell：新增 `scripts/lib/path-guard.ps1`，删除 / 移动 / 覆盖只允许走 `Invoke-GuardedFileOperation`。
     - 目标先规范化为绝对路径并逐级解开 symlink / junction；
     - 必须落在显式允许根之下，Windows 下不区分大小写，按路径分隔符做边界判断；
     - 拒绝驱动根 / UNC 根、用户主目录本身及其祖先与内部路径、空值、`$null`、`$VAR` / `%VAR%` 未展开变量；
     - 默认 dry-run，显式 `-Apply` 才执行；执行前打印绝对路径、类型与条目数，并复核一次；
     - 全部使用 `-LiteralPath`。
   - Go：新增 `tools/pathguard`，删除必须经 `RemoveAll` / `RemoveFile`，默认 dry-run、确认清单 JSONL、`go test` 覆盖同一组拒绝用例。
   - Rust：新增 `src/safety.rs`，语义与 PowerShell 版一致，已接入 `--demo` 临时目录、迁移快照、导出失败清理、更新 `.part` / 旧程序清理。
   - Shell：新增 `scripts/lib/path-guard.sh`，`test-check-version.sh` 与 `test-linux-migrate.sh` 的 `rm -rf` 改为默认 dry-run、显式 `--apply`。
2. **脚本层整改**
   - 所有 `scripts/*.ps1` 开头加 `Set-StrictMode -Version Latest`；
   - 禁止再用 `$home` / `$profile` 这类与只读变量重名的自定义变量；
   - 测试临时目录默认从 `$env:TEMP` 改为仓库 `tmp/`（D: 盘），不再默认在 C: 盘用户目录附近写删。
3. **事故记录与审计**
   - `docs/INCIDENT-2026-11-06.md`：发生了什么、根因、影响范围、整改内容、防复发措施。
   - `docs/PATH-SAFETY-AUDIT.md`：全仓库删除 / 移动 / 覆盖逐项清单与处置。
4. **自测**
   - `scripts/test-path-guard.ps1`：`C:\Users\Tyler Zhang`、`C:\`、`$env:USERPROFILE`、空字符串、`$null`、`..\..\Users`、未展开变量必须全部被拒；允许根下的临时目录必须放行；默认 dry-run 不删除。
   - `src/safety.rs` 单元测试：空路径、文件系统根、主目录及祖先、未展开变量、允许根本身被拒；临时目录子项放行并删除。

## 事故摘要

2026-11-06，真实升级验证脚本中把测试目录命名为 `$home`。PowerShell 7 的 `$HOME` 是只读变量，赋值报错后脚本继续执行 `Remove-Item $home -Recurse -Force`，实际作用于 `C:\Users\Tyler Zhang`，造成用户目录内容丢失。删除未进入回收站，恢复条件受限。

完整记录见 `docs/INCIDENT-2026-11-06.md`。本版不把它写成免责声明，而是把变量命名、默认 dry-run、允许根、删除前打印、错误即停这些约束固化到代码与脚本里。

## 已知限制与未验证项

- **未做系统级代码签名**：Windows 可能提示来源不明；更新包由 minisign 清单签名并以公钥校验，这与系统代码签名是不同层面的机制。
- **Linux 真实替换未实跑**：Linux 替换 / 重启代码路径已实现，但本机验收只在 Windows 上完成真实替换与自动重启。
- **面板不带内置 HTTPS**：默认只监听 `127.0.0.1`；对外服务需自行加反向代理、HTTPS 与强口令。
- 其余限制与 1.0.1 相同：hysteria2 入站未验证、mihomo 普通 Reality 未复测、xhttp 仅 xray 客户端、单实例单数据目录。

## 安装与升级

附件与 1.0.1 相同：Linux 二进制、Windows 二进制、demo 页面与 `SHA256SUMS`。Linux 二进制以 Debian 12（glibc 2.36）为基线。

从 1.0.1 升级：设置页「检查更新」→ 发现 1.0.2 → 「更新」→ 下载 → 校验 → 替换 → 进程退出 → 自动重启。1.0.1 已具备更新入口，可以走真实自更新。

## 校验

`SHA256SUMS` 随附件发布，Linux 可用 `sha256sum -c SHA256SUMS` 校验；两个二进制的 `--version` 均为 `berthio 1.0.2`，tag 与 `Cargo.toml` 版本一致。
