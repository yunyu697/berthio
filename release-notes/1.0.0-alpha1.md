# Berthio 1.0.0-alpha1

第一个里程碑（M1）：可运行的骨架 + 入站后端 + 设计稿前端接真实接口。

## 本里程碑包含

- **单二进制服务骨架**：`berthio serve` 形态，配置与状态落盘（`config/panel.json`、`state/state.json`），写入走 tmp → `.bak` → rename 的原子替换。
- **入站接口**：入站列表、新建向导默认值（6 步 / 4 协议 / 端口候选探测）、新建入站、按入站管理客户端。
- **配置导出**：mihomo（Clash Meta）YAML 与 sing-box JSON 预览、下载；L0 结构引用 / L1 枚举版本门禁 / L2 真实二进制自检三层校验；订阅令牌（明文只返回一次，服务端存 SHA-256）。
- **规则集目录**：40 条规则集 + 6 套预设（仅目录与内联生成，镜像下载属于 M2）。
- **内核能力探测与版本矩阵**：PATH、`tools/kernel/<name>/<ver>/`、`runtime/kernels/<name>/`、`BERTHIO_KERNEL_DIR` 多来源探测；缺失二进制的能力一律标「未验证」。
- **前端**：沿用设计稿同一套 DOM/CSS，不改变版式，只接真实接口。
- **demo**：`berthio --demo` 演示模式（临时目录、只听 127.0.0.1、内置演示数据、不启停真实内核），另有单文件静态 demo。
- **版本与 CI**：版本号单一来源（`Cargo.toml`，构建时注入），`scripts/check-version.sh` 校验格式 / tag 一致性 / alpha 序号单调，CI 与 Release 均跑在 Linux runner。

## 本机实测（Windows，2026-11-06）

用真实二进制对同一份导出做了 L2 自检：

| 目标 | 二进制 | 结果 |
| --- | --- | --- |
| mihomo | v1.19.33 | `mihomo -t -f` PASS（desktop / side / router 三种场景） |
| sing-box | 1.14.4 | `sing-box check -c` PASS（desktop / side / router 三种场景） |
| xray | 未安装 | **未验证**：没有任何 `xray -test` 结果，相关能力不得当成已验证 |

sing-box 1.14.4 的自检还实际拦下过一次真实缺陷：缺少 `route.default_domain_resolver` 在 1.14 是硬错误，修正后才 PASS。

## 已知限制

- **xray 未接入**：M1 只做能力探测与版本矩阵，VLESS/Reality 入站的服务端能力全部标「未验证」。
- **只支持 VLESS 入站**：hysteria2 / tuic 等返回「不支持（M2）」。
- **L2 只在有对应二进制时成立**：二进制缺失时为 `UNVERIFIED`，整体结论为 `WARN`，不会写成「已验证」。
- **sing-box 只实测 1.14.4**：1.11–1.13 档位是建档结论，本机未逐档跑二进制。
- **仅本机使用**：默认监听 `127.0.0.1:18080`，无远程鉴权（M3）。
- **TLS 证书**：不做 ACME / 自签签发，只接受已有证书路径。
- **3x-ui 迁移未开工**：本版没有任何写入既有 3x-ui 配置的代码路径。
- **规则集镜像**：M1 只有官方源 URL，可换源下载在 M2。

## 注意：alpha 不建议生产使用

`1.0.0-alpha1` 是里程碑快照，接口与状态结构都会变，**不建议用于生产环境**。正式版 `1.0.0` 会在全部里程碑完成后发布。

## 附件与 demo

- `berthio-1.0.0-alpha1-linux-x86_64`：Linux 二进制（前端静态资源已打进同一产物）。
- `berthio-1.0.0-alpha1-windows-x86_64.exe`：Windows 交叉编译产物（若 CI 上交叉编译失败则不含此项）。
- `berthio-1.0.0-alpha1-demo-m1.html`：M1 静态单文件 demo（双击打开即可，内置演示数据）。
- `SHA256SUMS`：以上附件的校验和。

本地起可交互 demo（后端演示模式，只监听 127.0.0.1）：

```bash
berthio --demo        # Windows: berthio.exe --demo
```

然后访问 <http://127.0.0.1:18090>。
